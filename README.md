# Gauss-Jordan-actividad-
# Método de Gauss-Jordan en Java

## 📋 Descripción del Proyecto
Este proyecto implementa el método de Gauss-Jordan para resolver sistemas de ecuaciones lineales de forma modular en Java. Se reutiliza la clase `Gauss` con el método de eliminación gaussiana desarrollado previamente, extendiendo su funcionalidad hasta obtener la matriz identidad y la solución directa del sistema.
